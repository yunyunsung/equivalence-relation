## 구성 조건별 구현

| 조건 | 내용 | 함수 |
|---|---|---|
| 1. 관계행렬 입력 | 5×5 행렬을 행 단위로 입력받아 2차원 리스트로 저장 | `input_matrix()`, `parse_row()` |
| 2. 동치 관계 판별 | 반사·대칭·추이 각각 판별, 결과에 따라 동치 여부 메시지 출력 | `is_reflexive()`, `is_symmetric()`, `is_transitive()`, `check_equivalence()` |
| 3. 동치류 출력 | 각 원소 a 의 동치류 [a] 출력 | `equivalence_class()`, `print_equivalence_classes()` |
| 4. 폐포 구현 | 반사·대칭·추이 폐포 변환, 변환 전/후 출력, 다시 판별 후 동치류 출력 | `reflexive_closure()`, `symmetric_closure()`, `transitive_closure()` (Warshall), `process_closures()` |

## 추가 기능

1. **입력 검증 및 재입력** — 개수 오류, 0/1 이외의 값 입력 시 이유를 알려주고 해당 행만 다시 입력 (`10100`, `1,0,1,0,0` 형식도 허용)
2. **반례(근거) 출력** — 성질을 만족하지 않을 때 어떤 순서쌍 때문인지 출력
3. **순서쌍 표기 및 분할 검증** — 관계를 순서쌍 집합으로 표기, 동치류가 A의 분할(A/R)인지 (합집합 = A, 서로소) 검증
4. **단계별 실행 · 메뉴 / 예제 / 무작위 생성 / 반복 실행** — 단계마다 [Enter] 로 화면을 나눠 결과 확인
5. **관계 방향그래프 시각화** — 입력 관계와 결과 관계를 그래프로 그려 `relation_graph.png` 로 저장 (폐포로 추가된 순서쌍은 빨간 점선, 동치류별 노드 색상)

## 실행 예시 (예제 2: 반사 X, 대칭 X, 추이 X)

```
R = {(1,1), (1,2), (2,3), (4,4), (5,4)}
  - 반사 관계 : X   근거: (2,2), (3,3), (5,5) ∉ R
  - 대칭 관계 : X   근거: (1,2) ∈ R 이지만 (2,1) ∉ R ...
  - 추이 관계 : X   근거: (1,2), (2,3) ∈ R 이지만 (1,3) ∉ R
동치 폐포 (반사 -> 대칭 -> 추이) 적용 후
  [1] = [2] = [3] = {1, 2, 3},  [4] = [5] = {4, 5}
  A/R = { {1, 2, 3}, {4, 5} }
```
